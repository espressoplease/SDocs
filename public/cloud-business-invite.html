How to use SmallDocs

Include the word "sdoc" in a request to your coding agent. Your agent creates the document in this workspace, opens it in your browser, and can find and update it later.

Example request

"Create an sdoc from these notes with a client brief, timeline, and budget chart."

See example sdocsExplore reports, code walkthroughs, presentations and financial models. See what an sdoc can containReview charts, diagrams, slides, computed sheets, code and video inside Markdown.
Free trial and pricing

The trial lasts 14 days and does not require payment details. Nothing is charged automatically. If your team subscribes, the price is $18 per workspace member each month. When the trial ends, creating and editing stops. Existing documents remain available to open and export for 30 days.

For developers: add sdocs to your application

The browser SDK renders SmallDocs inside your own application. Supply Markdown from your application and render the same prose, diagrams, charts, sheets, slides, math, code and video components. The SDK is priced separately from SmallDocs Cloud. Contact sales if you want to evaluate it.

Read the SDK guideReview installation, rendering, lifecycle methods and framework examples.
Cloud documents and access

Documents and revision history are stored in SmallDocs Cloud. Workspace membership, project grants, and document permission groups control who can open and edit each document. SmallDocs manages the encryption keys required to provide authorised access. You can export the Markdown while the documents remain available.
